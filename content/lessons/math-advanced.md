## Quadratics

- Vertex form $f(x) = a(x - h)^2 + k$: vertex $(h, k)$; opens up if $a > 0$.
- Standard form $ax^2 + bx + c$: vertex at $x = -\frac{b}{2a}$.
- Factored form $a(x - r)(x - s)$: zeros $r$ and $s$; vertex halfway between them.

## Exponentials

$f(t) = a \cdot b^t$: $a$ is the starting value, $b$ is the growth factor.

- Growth by $r\%$: $b = 1 + r$. Decay by $r\%$: $b = 1 - r$.
- "Doubles every 3 years": $a \cdot 2^{t/3}$.

## Worked example

A ball’s height is $h(t) = -16t^2 + 64t + 5$. The maximum is at $t = -\frac{64}{2(-16)} = 2$, so $h(2) = 69$ feet.

## Quadratic equations

1. Try factoring: $2x^2 - 5x - 3 = (2x + 1)(x - 3)$.
2. Otherwise use $x = \dfrac{-b \pm \sqrt{b^2 - 4ac}}{2a}$.
3. The **discriminant** $b^2 - 4ac$ tells you the number of real solutions: positive → 2, zero → 1, negative → 0.

## Radical equations

Square both sides, solve, then **check every solution** in the original. Squaring can add extra solutions that don’t work.

## Systems with a curve

Set the expressions equal: $x^2 - 4 = 3x$ gives $x^2 - 3x - 4 = 0$, so $x = 4$ or $x = -1$.

## Worked example

$x^2 + kx + 25 = 0$ has exactly one solution when $k^2 - 100 = 0$, so $k = 10$ if $k$ is positive.

## Toolkit

- Distribute and combine like terms.
- Special products: $(a+b)^2 = a^2 + 2ab + b^2$, and $a^2 - b^2 = (a-b)(a+b)$.
- Exponents: $x^m x^n = x^{m+n}$, $(x^m)^n = x^{mn}$, $x^{-n} = \frac{1}{x^n}$, $x^{m/n} = \sqrt[n]{x^m}$.
- **Remainder theorem:** dividing $p(x)$ by $x - k$ leaves remainder $p(k)$.

## The number-plug check

If you can’t see the algebra, pick $x = 2$, evaluate the original expression, and evaluate each choice. The equivalent one gives the same value (check a second number if two choices match).

## Worked example

$(2x - 3)^2 = 4x^2 - 12x + 9$, so in $4x^2 + bx + 9$ we have $b = -12$.
